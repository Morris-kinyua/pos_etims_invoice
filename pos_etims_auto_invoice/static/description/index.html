🧾 POS eTIMS Auto Invoice

Streamline Your Kenyan Tax Compliance with Automated Invoice Processing

📋 Overview

This powerful module revolutionizes invoice management for Kenyan businesses using Odoo POS. It automatically creates, posts, and pays invoices when you validate POS orders, then seamlessly integrates with Kenya Revenue Authority's eTIMS system to ensure full tax compliance.

Say goodbye to manual invoice processing and eTIMS submission! Everything happens automatically in the background while you focus on serving your customers.

✨ Key Features

🚀 Automatic Processing

  • Auto-Post: Invoices posted instantly
  • Auto-Pay: Payments registered automatically
  • Auto-Reconcile: Full reconciliation done

🇰🇪 eTIMS Integration

  • Automatic Submission: Sent to KRA eTIMS
  • Error Handling: Robust failure management
  • Logging: Complete audit trail

📄 Enhanced Invoices

  • eTIMS Fields: All KRA details displayed
  • QR Codes: Verification QR codes
  • Professional Reports: Print-ready invoices

🛡️ Reliability

  • Non-Blocking: Errors don't stop sales
  • Comprehensive Logs: Easy debugging
  • Tested: Production-ready code

🔄 How It Works

  1. Customer Checkout: Create POS order and select "Invoice" option
  2. Click Validate: Press the validate button in POS interface
  3. Auto-Create Invoice: System generates customer invoice automatically
  4. Auto-Post Invoice: Invoice is posted without manual intervention
  5. Auto-Register Payment: Payment recorded using POS payment method
  6. Auto-Reconcile: Payment reconciled with invoice
  7. eTIMS Submission: Invoice sent to KRA eTIMS system
  8. Display Details: eTIMS receipt number, QR code, and control unit shown on invoice

⚙️ Technical Information

Version: 15.0.1.0.0

Odoo Version: 15.0

Dependencies:

  • point_of_sale (Odoo Core)
  • account (Odoo Core)
  • l10n_ke_etims_vscu (Kenya eTIMS Integration)

Models Extended:

  • pos.order - Automatic invoice processing
  • account.move - eTIMS display enhancements
⚠️ Important: This module requires the l10n_ke_etims_vscu module (Kenya eTIMS Integration for Odoo v15) to be installed and properly configured with your KRA eTIMS credentials.

🚀 Installation

  1. Ensure l10n_ke_etims_vscu module is installed and configured
  2. Install this module from Odoo Apps
  3. Configure your POS to use invoice option
  4. Start processing orders - automation happens automatically!
